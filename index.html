Recommended Font Pairings

Poppins + Inter

Use Poppins for headings and Inter for body text. This creates clear hierarchy while maintaining readability.

Inter + Roboto Mono

Use Inter for general content and Roboto Mono for code snippets and technical details.

Text Styles

H1: Main Page Heading

.main-heading
  • Font Family: Poppins
  • Font Size: 3rem (48px)
  • Font Weight: 700 (Bold)
  • Line Height: 1.2
  • Letter Spacing: -0.5px
  • Color: var(--text-primary)
  • Margin Bottom: 1.5rem
.main-heading {
  font-family: 'Poppins', sans-serif;
  font-size: 3rem;
  font-weight: 700;
  line-height: 1.2;
  letter-spacing: -0.5px;
  color: var(--text-primary);
  margin-bottom: 1.5rem;
}

H2: Section Heading

.section-heading
  • Font Family: Poppins
  • Font Size: 2rem (32px)
  • Font Weight: 600 (Semi-bold)
  • Line Height: 1.3
  • Color: var(--text-primary)
  • Margin: 2rem 0 1rem 0

}

P: Body Text / Paragraph

.body-text

This is an example of body text. A well-designed paragraph should be easily readable with appropriate line height and contrast. Good typography enhances readability and user experience. Keep paragraphs concise and focused on a single idea.

  • Font Family: Inter
  • Font Size: 1rem (16px)
  • Font Weight: 400 (Regular)
  • Line Height: 1.6
  • Color: var(--text-secondary)
  • Margin Bottom: 1rem
  • Max Width: 70ch (optimal readability)
.body-text {
  font-family: 'Inter', sans-serif;
  font-size: 1rem;
  font-weight: 400;
  line-height: 1.6;
  color: var(--text-secondary);
  margin-bottom: 1rem;
  max-width: 70ch;
}
A: Hyperlink / Anchor Text .text-link
  • Font Family: Inter
  • Font Size: 1rem (16px)
  • Font Weight: 400 (Regular)
  • Color: var(--primary-color)
  • Text Decoration: none (by default)
  • Hover: text-decoration: underline
  • Transition: color 0.2s ease
.text-link {
  font-family: 'Inter', sans-serif;
  font-size: 1rem;
  font-weight: 400;
  color: var(--primary-color);
  text-decoration: none;
  transition: color 0.2s ease;
}

.text-link:hover {
  text-decoration: underline;
}
Code: Inline Code Snippet .inline-code
  • Font Family: 'Roboto Mono', monospace
  • Font Size: 0.9rem (14.4px)
  • Font Weight: 400 (Regular)
  • Background: var(--code-bg)
  • Color: var(--accent-color)
  • Padding: 0.2rem 0.4rem
  • Border Radius: 4px
  • Border: 1px solid var(--border-color)
.inline-code {
  font-family: 'Roboto Mono', monospace;
  font-size: 0.9rem;
  font-weight: 400;
  background: var(--code-bg);
  color: var(--accent-color);
  padding: 0.2rem 0.4rem;
  border-radius: 4px;
  border: 1px solid var(--border-color);
}
